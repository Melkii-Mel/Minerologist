#    Аммонит Quenstedticeras, продольный срез раковины (~165 млн лет назад)
[/center]
внутренние камеры раковины заполнены пиритом — минералом с золотистым блеском. Виден узор из перегородок между камерами, по которому определяют вид аммонита. Д. Дубки, Саратовская область. Дар В. А. Козлова, 2000 г.
